# Capital Budgeting & Investment Decision Analysis

## Meridian Consumer Products Ltd.

A comprehensive capital budgeting and investment decision analysis project evaluating a fictional capacity-expansion investment using financial modeling, discounted cash flow techniques, risk analysis and strategic decision frameworks.

---

## 📊 Project Overview

This project evaluates a proposed capacity-expansion investment for **Meridian Consumer Products Ltd.**, a fictional Indian consumer-products company.

The analysis focuses on whether the proposed investment creates sufficient economic value relative to its required return, capital requirements and associated risks.

The project uses an integrated investment-analysis framework covering:

- Incremental Cash Flow Analysis
- Net Present Value (NPV)
- Internal Rate of Return (IRR)
- Payback Period
- Discounted Payback
- Discounted Cash Flow Analysis
- Terminal Value
- Working Capital
- Sensitivity Analysis
- Scenario Analysis
- Alternative Investment Comparison
- Strategic Fit Analysis
- Investment Risk Assessment
- Decision Thresholds
- Implementation Planning
- Post-Investment KPI Monitoring

---

# 🎯 Project Objectives

The primary objectives are to:

1. Build an incremental project cash-flow model.
2. Calculate Net Present Value (NPV).
3. Calculate Internal Rate of Return (IRR).
4. Estimate the payback period.
5. Evaluate discounted cash-flow recovery.
6. Analyze terminal value assumptions.
7. Evaluate working-capital requirements.
8. Perform NPV sensitivity analysis.
9. Conduct downside, base-case and upside scenarios.
10. Compare alternative investment opportunities.
11. Evaluate strategic fit.
12. Identify investment risks.
13. Establish investment decision thresholds.
14. Develop an implementation roadmap.
15. Create a post-investment KPI framework.
